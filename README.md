🎬 Movie Recommender System

A **content-based movie recommendation system** built with Python, Scikit-learn, and Streamlit using the **TMDB 5000 Movie Dataset**.

🚀 Features

* 🎥 Content-based movie recommendations
* 🧠 `CountVectorizer` for feature extraction
* 📐 Cosine similarity for movie matching
* 🌐 Interactive Streamlit web app
* 🧹 Data preprocessing with Pandas

🧠 How It Works

```text
Movie Metadata
      ↓
Data Preprocessing
      ↓
Feature Extraction
      ↓
CountVectorizer
      ↓
Cosine Similarity
      ↓
Movie Recommendations
```

The system combines movie information such as **genres, keywords, cast, crew, and overview** to find movies with similar characteristics.

 🛠️ Tech Stack

* Python
* Pandas
* NumPy
* Scikit-learn
* Streamlit
* Git & GitHub

 ⚙️ Installation

```bash

cd movie-recommender-system
python3 -m venv venv
```
